Sign Bridge — 70-Sign Indian Sign Language (ISL) Recognition & Learning Platform
================================================================================

1. Prerequisites
----------------
- Python 3.11 or 3.12 (`python --version`)
- A webcam (720p 16:9 recommended; 640x480 4:3 webcams are automatically aspect-normalized)
- Linux headless servers only (if `libEGL.so.1` / `libGLESv2.so.2` are missing):
  sudo apt-get update && sudo apt-get install -y libegl1 libgles2 libgl1

2. Virtual Environment & Dependency Setup
-----------------------------------------
Linux / macOS:
  python3 -m venv .venv
  source .venv/bin/activate
  pip install --upgrade pip
  pip install -r requirements.txt

Windows (PowerShell):
  python -m venv .venv
  .\.venv\Scripts\Activate.ps1
  python -m pip install --upgrade pip
  pip install -r requirements.txt

Note: `requirements.txt` pins `mediapipe==0.10.31`, `opencv-python-headless==4.11.0.86`,
`numpy==2.0.2`, `tensorflow==2.20.0`, `gTTS==2.5.1`, and `espeakng-loader==0.2.4` so
dependencies install cleanly without OpenCV/NumPy conflicts and offline TTS works out of the box.

3. Running the Web Application Locally
--------------------------------------
  python app.py

Open http://localhost:5000 in Chrome or Edge and allow camera access:
- Register / Sign In: http://localhost:5000/login
- Dashboard & Analytics: http://localhost:5000/dashboard
- AI Sign Tutor (Ghost-Hand Overlay, Practice & Time Attack): http://localhost:5000/tutor
- 70 Right-Hand Reference Gesture GIF Library: http://localhost:5000/gestures
- Live ISL Translator (70-Sign Webcam Recognition -> 9 Indian Languages + SOV Gloss GIFs + MP3 Audio):
  http://localhost:5000/translator

4. Running the Automated Verification & End-to-End Webcam Test Suite
--------------------------------------------------------------------
  pytest -v

This runs both `tests/test_translator_pipeline.py` and `tests/test_webcam_recognition_70.py`,
verifying:
- End-to-end MediaPipe HandLandmarker video frame decoding -> preprocessing -> kinematic extraction -> inference
- Confused class separation (`Police`, `Bicycle`, `Doctor`, `Hello`, `How are you`, `happy`, `Father`, `Mother`)
- Multi-position, multi-scale, `4:3` vs `16:9` aspect ratio, and left-handed vs right-handed signer invariance
- Strict `"Unknown"` rejection on no-hand frames, sparse flicker, random motion, and real out-of-distribution ISL signs
- Exact `70 / 70` alignment between recognized class labels, `label_map.json`, and displayed right-hand GIFs
- Preservation of authentication, dashboard, AI Tutor scoring, ghost-hand overlay, leaderboard, and 9-language audio

5. Re-running Dataset Audit & Model Training
--------------------------------------------
  python scripts/train_and_evaluate_webcam_model.py

Training logs, per-class precision/recall/F1 across all 70 signs, and 70x70 confusion matrices
are written to `models_LSTM/analysis/`. Pre-retrain checkpoints and code backups are preserved in
`backups/pre_retrain_3cdac8c/`.
